# 2027 Fall 计算机类硕士留学申请管理页面

这是一个单文件 HTML 留学申请管理页面，面向 2027 Fall 计算机、人工智能、软件工程、数据科学和机器人方向硕士申请。

## 内容

- 欧洲大陆 QS 前 150 英语授课计算机类硕士项目
- 香港、新加坡、英国、澳大利亚、澳门等地区的申请记录
- 学校官网项目要求、英语要求、申请材料、学费和生活费规划
- 欧洲院校官方学费集中表
- 申请状态、材料清单、时间轴和个人背景匹配分析

## 使用

直接用浏览器打开：

`study_abroad_2027_fall_cs_application.html`

页面无后端、无数据库，数据和交互逻辑均嵌入 HTML，可离线使用。

## 数据说明

学校和项目费用优先引用学校官网、官方招生页面、官方 handbook 和官方 fee schedule。官网尚未公布固定金额、或按身份/学分/年度动态计算的项目，会在页面中明确标注“需复核”。
